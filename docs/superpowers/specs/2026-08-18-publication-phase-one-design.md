# Mizuki 白日出版版第一阶段设计

## 目标

以 Mizuki 为技术与内容底座，快速交付一个可本地使用、可静态构建的个人综合博客出版版。第一阶段优先建立稳定的信息架构、文章阅读链路和基础功能分区；复杂主页与个人主站留到后续阶段。

内容定位为开发记录、游戏、音乐和生活随笔，不包含桌面折腾。

## 硬性边界

- 第一阶段只制作白日风格，不实现夜间主题。
- 不读取、复制或使用用户本地壁纸，壁纸适配明确延期。
- 不擅自下载或使用其他来源图片。需要文章封面、相册、友链头像或游戏封面时，先提交选题、尺寸与格式清单，由用户下载并提供。
- 不接入分析、广告、远程字体、远程音乐、Meting、Memos、Bangumi/Bilibili 同步、Live2D、Twikoo、Giscus 或公共 PlantUML 服务。
- 不实现真实后台、账号系统或数据库。
- 旧项目 `/home/tokinagi/aero-room-blog` 不修改。

## 第一阶段信息架构

### 全局导航

- 主页：先提供简洁出版入口，复杂视觉首页最后制作。
- 个人主站：保留入口和明确的“建设中”状态，复杂前端最后制作。
- 工具导航：本地静态工具分类与空状态。
- 文章：归档、标签、文章列表。
- 联系我：友链、留言。
- 我的：日历、相册、赞助、音乐、小游戏、关于。
- 搜索：使用 Mizuki/Pagefind 的本地静态索引能力；开发模式提供清楚的未生成索引提示。

### 第一阶段可用功能

- 归档：从本地文章数据计算文章总数、创作跨度、本月文章和按年/月分组的时间线。
- 标签：先交付可搜索、可展开、可进入文章结果页的普通标签视图；关系图动画延期。
- 文章列表：置顶区、普通列表、分页或渐进加载、最新/最早排序；“热门”在没有可信访问统计时不伪造。
- 友链：本地数据驱动的分类筛选和响应式卡片；申请入口显示联系说明，不提交远程表单。
- 留言：第一阶段只交付静态说明与未启用状态，不展示伪造留言，不收集访客数据。
- 日历：展示本地文章发布日期，不请求第三方日历服务。
- 相册：交付页面结构和空状态；待用户提供图片后再填充。
- 赞助：交付说明页面，不接支付或二维码素材。
- 音乐：交付收藏列表结构，不接远程音源、不自动播放。
- 小游戏：交付“小游戏”入口和游戏列表空状态；具体游戏另行确认。
- 关于：使用可集中编辑的本地 Markdown 内容。

## 视觉与布局

- 参考用户截图中的悬浮胶囊导航、面包屑、下拉菜单、宽阔正文和清晰层级，但不复制站点品牌与素材。
- 目标质量高于截图：统一间距与字号体系、强化阅读宽度、焦点态、空状态、移动导航和内容密度控制。
- 白日风格使用轻量 Aero 语汇：浅蓝灰背景、半透明白色表面、细边框、柔和内高光与克制阴影。
- 不使用背景图片；视觉层次完全由颜色、渐变、边框和排版建立。
- 桌面端采用品牌区、居中主导航和搜索入口；移动端使用紧凑顶栏与可展开菜单。
- 文章正文优先，阅读宽度约 720–820px；目录仅在足够宽的视口出现。

## 技术方案

- 从官方 Mizuki 仓库建立独立项目，并保留上游许可证与第三方声明。
- 使用本地内容模式，禁用内容仓库同步和所有可选外部集成。
- 先审计锁文件、生命周期脚本、依赖版本、许可证和构建期网络行为，再安装依赖。
- 内容保存在 `src/content/`，导航与功能页面数据保存在 `src/data/` 或 Mizuki 现有配置模块。
- 页面功能尽量复用 Mizuki 的既有组件；仅为第一阶段边界做删除、配置和针对性改造。
- 不为了关系图、留言或视觉装饰新增依赖。

## 响应式与无障碍

- 验证 320px、768px、1024px 和 1440px。
- 所有交互具有键盘可达性、可见焦点和清晰可访问名称。
- 每页恰好一个主标题，标题层级连续。
- 动效遵守 `prefers-reduced-motion`。
- 移动端不依赖悬停，菜单、筛选和排序触控目标不小于 44px。

## 验收标准

- 全部第一阶段路由可访问，无死链接；延期功能显示诚实、清楚的状态。
- 本地示例文章可完成“列表 → 标签/归档 → 文章正文”阅读链路。
- 文章排序、标签筛选和友链分类可用。
- 页面不引用本地壁纸、远程字体、分析脚本或未经用户确认的图片。
- `pnpm check`、`pnpm type-check`、`pnpm test` 和 `pnpm build` 通过；若上游命令因已移除的远程功能需要调整，必须在脚本与文档中说明。
- 浏览器控制台无错误，四档宽度无横向溢出，键盘导航可用。
- 提供本地预览地址供用户试用。

## 延期范围

- 完整视觉主页与个人主站。
- 夜间主题与自动主题切换。
- 壁纸系统。
- 交互式标签关系图。
- 真实留言、评论、账号和数据库。
- 相册图片、远程或本地音频内容、具体小游戏。
- 任何需要用户另行下载素材的视觉内容。
